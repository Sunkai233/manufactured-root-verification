## 二、四路成熟工程调研 → 可执行结论(浓缩)

**(1) df32 多精度(CAMPARY/QD/twofloat/Thall)**
- EFT 基元:TwoSum(6flop) / Fast2Sum(3,需|a|≥|b|) / TwoProd=`p=a*b;e=fma(a,b,-p)`(2flop)。
- 双档加法:sloppy(相消处无界,只用于远离根)vs accurate two-sum(界 3u²≈2^-46)。**靠近根/做残差的步必须 accurate**。
- 超越函数:exp 用 Cody–Waite 约减 + ldexp(精确);**log 用对 df-exp 做 1 步 Newton**(fp32 种子已 23 位,平方到 46 位,现码用 3 步是浪费);sin/cos 用 π/2 约减+象限重构,minimax 免 df_div。
- df32 有效精度 ≈ **44–46 位**(非名义 48);u=2^-24,u²=2^-48。
- ★★头号坑:`-use_fast_math`/FMA 收缩会把 TwoSum/TwoProd 的误差项优化成 0 → 高精度全毁。对 EFT 文件 `#pragma STDC FP_CONTRACT OFF` 或全用 `__fadd_rn/__fmul_rn/__fmaf_rn`。FTZ 与 fp32 除法非正确舍入→用硬件倒数+df-Newton。
- 何时 df32 更快:C<R 且吞吐受限。B300 R=71.4,纯 FMA 满足(实测 3.8×);标量求解器延迟受限+超越太贵则不赢。

**(2) Smale α 认证(alphaCertified / Hauenstein–Sottile / Wang–Han)**
- β=|f/f′|;γ=sup_{k≥2}|f^{(k)}/(k! f′)|^{1/(k−1)};α=βγ。阈值 **α<(13−3√17)/4≈0.157671** ⇒ x 是 approximate zero 且 |x−ξ|≤2β。硬边界 α≥1/4 必失败。
- **γ 闭式** = max(小 k 有限项 k=2..8, 尾部 1/dist(x,最近奇点))。本族:exp/sin/cos 尾部=0(整函数),ln(1+cx) 尾部=1/|x+1/c|。→ γ≈max(|f″/(2f′)|, 1/|x+1/c|)。
- **固定步数许可证**:approximate zero ⇒ e_k≤2^{2−2^k}β,解出 **k_max=⌈log₂(2+log₂(β/ε))⌉**;fp64 β≈1 → 6 步牛顿封顶;高阶(Householder-3, 4阶)更少 ~3-4 步。
- ★正确口径:画**达 ε 所需步数分布**——认证点退化成点质量(方差≈0),未认证但收敛的点长尾(线性瞬态/吸引环/混沌);GPU 上前者步数一致=零发散,后者参差=发散。**这才是认证价值,不是收敛成功率**。
- 认证与迭代解耦:用 Newton α 认证,认证后跑 Halley/Householder 更少步;导数复用。边缘点(α∈[0.13,0.157])建议升 long double/MPFR 或阈值取保守 0.13。

**(3) C++ 前向 AD(Ceres Jet / autodiff / Blondel 隐式)**
- 照 Ceres `Jet<double,N>` 手写 `Dual5{double val; double d[5];}`,链式法则写死每个 op(mul: 乘积法则;div: 商法则;exp/log/sin/cos 见备忘)。θ=(a,b,c,d,ω) N=5,一趟前向出全部偏导。
- 三路一致性:(a) unrolled Dual 穿 Householder 迭代——Householder 在单根 ∂_xG(x*)=0,**收敛后再走 1 步 unrolled 梯度即等于隐式闭式**,几乎无 burn-in;(b) 隐式标量 `dx̂/dθ_i=−(∂F/∂θ_i)/(∂F/∂x)`;(c) 中心差分穿求解器。
- ★步长纠正:中心差分 h=**u^{1/3}·max(|θ_i|,1)**(非 u^{1/2}),地板 u^{2/3}≈4e-11;求解器内部 tol 必须 ≪ u^{2/3},两侧不得跨分支/跨步数。
- complex-step 只能验单个全纯子式(∂F 解析式),**不能穿含分支的求解器**(abs/比较/if 非全纯)。
- 判据:(a)↔(b) ≲1e-11(κ·u,病态按 κ 放宽);(a/b)↔(c) ≲1e-6 即"可微性成立"。

**(4) 汇编级验证方法论(cuobjdump/nvdisasm/objdump)**
- 编译:`-lineinfo`(**不是 -G**,-G 关优化拆 FMA 插分支毁证据);默认 `--fmad=true`;CPU `-O3 -march=native`(不加则无 FMA/AVX)。
- 反汇编:`cuobjdump -sass ./bin` / `--function "<mangled>"`;`nvdisasm -cfg -fun <fn> x.cubin | dot -Tpng`(CFG:固定步=直链单回边,早退=菱形)。抽 cubin:`cuobjdump -xelf all`。
- 无发散信号:`grep -cE 'BSSY|BSYNC'`=0 且 `grep -cE '@!?P[0-9]+ +BRA'`=0,循环体为直线 FMA 链。发散信号:ISETP/FSETP→BSSY→@P BRA→BSYNC。★别把 `@P FFMA`(谓词化 ALU,非发散)当分支;只统计谓词溯源到数据的分支。
- 数 FMA 印证融合:degree-d Horner = d 条 FFMA/DFMA 且无独立 FADD/FMUL;TwoProd=`DFMA R_e,a,b,-p`(带负号第三操作数)。
- 无 ncu 时:CUDA event(sync→record→launch→record→sync→median,warmup,套 K 次摊 launch);占用率 `cudaOccupancyMaxActiveBlocksPerMultiprocessor` 静态算;roofline 手算(SASS 数 FMA×2×trip×threads / 字节)。
- CPU:`objdump -d -Mintel`;向量化=`vfmadd*pd/ps + ymm/zmm`(标量 `vfmadd*sd/xmm`=没向量化);无内层分支=只有底部计数器 `jne` 回边;`perf stat cycles,instructions,branches,branch-misses`;`-fopt-info-vec`。
