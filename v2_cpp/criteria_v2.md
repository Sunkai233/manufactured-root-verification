## 统一定义(消歧)
- **认证** = C++ `alpha.hpp` 算 α=βγ,阈值 **(13−3√17)/4 = 0.157671**。★**必须用 long double**:double 的 β=|f(x0)/f'(x0)| 在 x0 近根时灾难性相消**恰好舍入成 0**(实测 2937 个,long double 仅 2 个),使 α=0 假认证极病态实例(真 α 高达 4e7)。稳健认证(long double,γ 在 x0)= **7558(46.13%)**、未认证 8826(53.87%)。对账:double(有 bug)9806、gen mpmath 参考 10605(gen 在 xstar 用 A_k 界算 γ,非标准 α 检验点+欠估真 γ,偏宽)。**采 46.13%**。
- **e_repr 唯一来源** = `|x̂ − x*|/max(|x*|,1)`,x̂ 取生产核 G3/G4/G5 固定 8 步输出,x* 取 mpmath 50 位真根。
- **条件数 κ** = parquet 的 kappa 列;γ 用实际导数闭式(k=2..9 已收敛 + ln 奇点尾)。

## 关键实测结果(取代旧结论)

**硬件(峰值微基准,推翻"B300 fp64 满速"):** B300 fp32 70933 / fp64 993 GFLOP/s → **R=71.4**;RTX5090 64106/1578 → R=40.6。两卡 fp64 皆重度削减,B300 绝对值(993)< 5090(1578)。df32 纯 FMA 反超 fp64(3.81× / 2.00×)。

**df32 慢的真因(非"fp64 快"):** 标量迭代延迟受限 + 超越函数指令暴涨。SASS:k_g3 **104 DFMA/13 BSSY**,k_g4 **0 DFMA/1267 FFMA/155 BSSY**,k_g5 111 FFMA/26 MUFU。

**认证价值=步数分布(非收敛率,认证用 long double):** 认证(n=7558)Newton 中位 2/均值 2.68/失败 0.75%(点质量);未认证(n=8826)中位 5/均值 6.11/失败 2.56%(长尾)。结论在修正认证后依然成立。注:未认证 step-0 偏高是被正确剔除的"x0≈根但极病态"实例(0 步收敛但非 approximate zero)。

**线程束浪费(HH3 步数封顶 ns=8,多调度键,自适应ε步数):** 随机 0.745 / κ排序 0.752 / **α排序 0.581(最优可实现)** / 认证标志排序 0.662 / 步数oracle 0.479(不可实现) / **固定步 0.000(靠构造,无早退分支)**。★诚实口径:**认证标志作调度键几乎无用(0.745→0.662),不是"认证降低发散";是固定步 G3 从构造上消除发散**。fig5 现运行时从真源算(不再硬编码)。

**G2/G3 等精度对照(饱和 REP=256, N=4.19M):** G3 394.3 / G2 395.6 M/s,精度同(p50 1.96e-11)。**反转旧报告"G2 514>G3 394"**——那是绝对残差阈早退给 G2 的离场券;公平步长停机后 G2 早退因线程束锁步零收益,固定步 G3 严格更优(同速同精度、无发散分支、确定、延迟可预测)。

**能耗(修正协议,扣空载,饱和吞吐):** G3 fp64 **0.257** / G4 df32 **0.674** / G5 fp32 **0.020** J/百万根。df32 在 B300 最费电(旧 0.438 是低 N 功率÷高饱和吞吐的错口径)。

### ★v4 构造偏置根治 + 双数据集 + M1–M9 + 基本极限

**构造偏置(已根治):** 旧 `gen_instances.py` 初值 `off∝1/γ`(logγ~logκ 相关 0.99)使高κ实例起跑即在地板处、根本不迭代(全体 ~21% 未移动),撑高 C2 并造 fig2 假下降支。v4 重构初值为**两种 κ 无偏方式**(gen 加 `--offset_mode`):
- **floorscaled** `|x0-x*|=M·κu·|x*|`(M=100):每实例起于地板上方固定 100 倍 → **全部真迭代~3步到地板**(0% 不动)。用于 **fig2/C2/M1-M9**。认证 50.2%,C2 **95.57%**,e_repr 认证子集 G3 **1.11e-13**/G4 5.31e-12/G5 1.44e-6(按精度 u 分层, 贴 κ·u)。
- **kindep** `|x0-x*|=δ·|x*|`(δ∈[1e-3,1e-1], κ无关):用于**认证价值实验(fig4/5)**——认证(3.5%)收敛到机器精度、未认证不收敛到真根,α 理论的干净分离。

**★基本极限(独立小结论):** 对 κ > 1/√u ≈ 1.3e8(fp64),根的条件地板 κu 超过其牛顿收敛盆地半径 ~1/κ,**任何有界初值都无法通过迭代到达地板**(必须一开始就置于地板处)。旧 ∝1/γ 构造正是靠预置 x0 于地板掩盖了此极限;κ 无偏初值把它暴露。故可迭代展示地板的 κ 上界 = 1/√u,与精度 u 直接挂钩(fig2 竖线标注)。

**M1–M9 阶次×精度全因子(floorscaled 数据, 饱和吞吐, 8步固定, `solver_matrix.cu`/`matrix_floor.csv`):**
- 吞吐(M根/s):fp64 Newton/Halley/HH3 = 525/459/398,df32 424/406/375,fp32 25367/22325/19878。**阶次↑→每步更贵吞吐↓;fp32 吞吐碾压 df32≈fp64**。
- 精度 e_repr p50:fp64 ~4e-11,df32 ~1.5e-9,fp32 ~1e-5(**按精度 u 分层**);阶次效应在 p99 尾部(fp64 HH3 5.8e-7 vs Newton 1.3e-4=高阶 8 步内更准)。det 全 1。

## 诚实边界
- C2 93.04% 不达 99.9%(极病态尾部 8 步未触底)。
- C4 多根:38.6% 良态实例 x*±0.2 内有第二根 → 从头 Brent 会解到别的根(故降级为设计边界参照);但 α 认证半径内第二根 0.00%,认证本身干净。
- C7 可微性 B↔C 差分通道仅 κ<1e4 有效;A↔B 解析互证全程有效。
- Brent 单核吞吐更高是预期(算得少),价值不在单点吞吐而在批量确定性 + 可微,按设计边界写。
