# 判据 v2(唯一权威)· 制造根验证基准

> 本文件**取代** `results/criteria.txt` 与 `REPORT_实验一_制造根验证.md` 中的结果表。
> 所有数字来自唯一真源 `instances.csv`(kappa/α/认证/e_repr/步数)+ 各 C++ 工具实测,消除旧版双认证定义与多 e_repr 来源。
> 硬件:B300(sm_103, CUDA13.2)+ 对照卡 RTX5090(abc66)。日期 2026-07-26。

## 统一定义(消歧)
- **认证** = C++ `alpha.hpp` 算 α=βγ,阈值 **(13−3√17)/4 = 0.157671**。★**必须用 long double**:double 的 β=|f(x0)/f'(x0)| 在 x0 近根时灾难性相消**恰好舍入成 0**(实测 2937 个,long double 仅 2 个),使 α=0 假认证极病态实例(真 α 高达 4e7)。稳健认证(long double,γ 在 x0)= **7558(46.13%)**、未认证 8826(53.87%)。对账:double(有 bug)9806、gen mpmath 参考 10605(gen 在 xstar 用 A_k 界算 γ,非标准 α 检验点+欠估真 γ,偏宽)。**采 46.13%**。
- **e_repr 唯一来源** = `|x̂ − x*|/max(|x*|,1)`,x̂ 取生产核 G3/G4/G5 固定 8 步输出,x* 取 mpmath 50 位真根。
- **条件数 κ** = parquet 的 kappa 列;γ 用实际导数闭式(k=2..9 已收敛 + ln 奇点尾)。

## 关键实测结果(取代旧结论)

**硬件(峰值微基准,推翻"B300 fp64 满速"):** B300 fp32 70933 / fp64 993 GFLOP/s → **R=71.4**;RTX5090 64106/1578 → R=40.6。两卡 fp64 皆重度削减,B300 绝对值(993)< 5090(1578)。df32 纯 FMA 反超 fp64(3.81× / 2.00×)。

**df32 慢的真因(非"fp64 快"):** 标量迭代延迟受限 + 超越函数指令暴涨。SASS:k_g3 **104 DFMA/13 BSSY**,k_g4 **0 DFMA/1267 FFMA/155 BSSY**,k_g5 111 FFMA/26 MUFU。

**认证价值=步数分布(非收敛率,认证用 long double):** 认证(n=7558)Newton 中位 2/均值 2.68/失败 0.75%(点质量);未认证(n=8826)中位 5/均值 6.11/失败 2.56%(长尾)。结论在修正认证后依然成立。注:未认证 step-0 偏高是被正确剔除的"x0≈根但极病态"实例(0 步收敛但非 approximate zero)。

**线程束浪费(HH3 步数封顶 ns=8,多调度键,floorscaled 数据集——有真实难度方差;fig5 运行时算):** 随机 **0.632** / κ排序 **0.268** / α排序 0.296 / 认证标志排序 **0.317** / 步数oracle 0.142(不可实现) / **固定步 0.000(靠构造,无早退分支)**。★口径修正:在有难度方差的无偏数据集上,**κ/α/认证 先验键均把浪费大幅降(0.63→~0.3)**——**反转了此前从有偏 legacy 数据集读出的"认证键无用(0.745→0.662)"**。注:kindep 数据集因固定相对起步、步数近均匀,warp-waste 仅 0.148、各键无差,不用于此论证。

**G2/G3 等精度对照(饱和 REP=256, N=4.19M):** G3 394.3 / G2 395.6 M/s,精度同(p50 1.96e-11)。**反转旧报告"G2 514>G3 394"**——那是绝对残差阈早退给 G2 的离场券;公平步长停机后 G2 早退因线程束锁步零收益,固定步 G3 严格更优(同速同精度、无发散分支、确定、延迟可预测)。

**能耗(修正协议,扣空载,饱和吞吐;数字照 `logs/energy_v2.log`):** G3 fp64 **0.2592** / G4 df32 **0.6678** / G5 fp32 **0.0200** J/百万根(P_idle 134.0W)。df32 在 B300 最费电(旧 0.438 是低 N 功率÷高饱和吞吐的错口径)。

### ★v4 构造偏置根治 + 双数据集 + M1–M9 + 基本极限

**构造偏置(已根治):** 旧 `gen_instances.py` 初值 `off∝1/γ`(logγ~logκ 相关 0.99)使高κ实例起跑即在地板处、根本不迭代(全体 ~21% 未移动),撑高 C2 并造 fig2 假下降支。v4 重构初值为**两种 κ 无偏方式**(gen 加 `--offset_mode`):
- **floorscaled** `|x0-x*|=M·κu·|x*|`(M=100):每实例起于地板上方固定 100 倍 → **全部真迭代~3步到地板**(0% 不动)。用于 **fig2/C2/M1-M9**。认证 50.2%,C2 **95.57%**,e_repr 认证子集 G3 **1.11e-13**/G4 5.31e-12/G5 1.44e-6(按精度 u 分层, 贴 κ·u)。
- **kindep** `|x0-x*|=δ·|x*|`(δ∈[1e-3,1e-1], κ无关)→ `instances_cert.csv`:用于 **fig4 认证价值(收敛分离)**——认证(**573, 3.5%**)收敛到机器精度 e_repr p50 **5.27e-16**、未认证不收敛到真根,α 理论的干净分离;β=0 相消也消失(x0 不贴根)。warp 调度(fig5)因 kindep 步数近均匀(waste 仅 0.148)改用 floorscaled。

**★β=0 相消的出现条件(旁证,已刻画):** double 下 β=|f(x0)/f'(x0)| 舍入成 0 的灾难性相消**不是普遍现象,而是"初值已压在精度地板上"这一特定构造的产物**(legacy ∝1/γ 令 |x0−x*| 随 γ 缩到 <κu)。反证:floorscaled(|x0−x*|=100κu 离根足够远)下 **long double 认证 8229 == double 认证 8229、β=0 计数为 0**,double 与 long double 判定不再有任何差异。故此坑的出现被刻画为"x0 距根 ≲ κu"的充分条件,而非一般 double 缺陷。

**★基本极限(独立小结论):** 严格地,牛顿(近似零)收敛盆地半径 ~ **α₀/γ**(α₀=0.157671);当条件地板 βu≈κu 超过 α₀/γ 时,**任何有界初值都无法通过迭代到达地板**(必须一开始就置于地板处)。本族 γ 与 κ 相关 0.99(非相等),用 1/κ 作量级估计得可迭代展示地板的 κ 上界 ≈ 1/√u ≈ 1.3e8(fp64)、直接由精度 u 决定。旧 ∝1/γ 构造靠预置 x0 于地板掩盖了此极限,κ 无偏初值把它暴露(fig2 竖线标注)。

**M1–M9 阶次×精度全因子(floorscaled 数据, 饱和吞吐, 8步固定, `solver_matrix.cu`/`matrix_floor.csv`):**
- 吞吐(M根/s,fp32 用快速内建 __expf 与 G5 一致):fp64 Newton/Halley/HH3 = **526/460/397**,df32 **424/406/374**,fp32 **42862/35511/28960**。**阶次↑→每步更贵吞吐↓;fp32 吞吐碾压 df32≈fp64**(fp32-HH3 28960 与能耗/等精度里的 G5 27959/28397 一致,~3%内)。
- 精度 e_repr p50:fp64 ~4e-11,df32 ~1.5e-9,fp32 ~1e-5(**按精度 u 分层**)。★p99 由"8 步预算未收敛"支配、与 u 无关:fp64-Newton 与 df32-Newton 的 p99 都是 **1.342e-04(逐位相同)**=收敛不足不是精度损失;阶次↑则 p99 下降(fp64 HH3 5.83e-7 vs Newton 1.34e-4)。det 全 1。

## 诚实边界
- **C2 95.57% 的前提**:floorscaled 初值把每实例置于**自身地板上方 100 倍**(用了 κ 先验=已知题目难度),故只能表述为"地板上方 100 倍起步、8 步预算内落进 4κu 的比例",不是一般精度保证;M1–M9 的吞吐/精度同带此前提。κ∈[1e6,1e8] 掉到 78.54% 正是 8 步预算的边际带(再多几步即补上)。
- **p99 是预算截断非精度损失**:等精度对照 G3/G2 的 relerr_p99 都 2.717e-3(p50 才 1.96e-11);M1–M9 里 fp64-Newton 与 df32-Newton 的 p99 逐位相同 1.342e-4——均为 8 步没收敛,与 u 无关,须与"尾部错根"和"精度地板"三者分清。
- C4 多根:良态 κ<1e4 内 x*±0.2 有第二根 **77.0%**、≥3 根 9.7%(long double 网格+关 FMA);α 认证半径内第二根 **0.03%**(≈0),认证本身干净。
- C7 可微性 B↔C 差分通道仅 κ<1e4 有效;A↔B 解析互证全程有效。
- Brent 单核吞吐更高是预期(算得少),价值在批量确定性+可微,按设计边界写。
- 认证价值(fig4)用 kindep 数据集(认证收敛/未认证不收敛的干净分离);warp 调度(fig5)用 floorscaled(有难度方差);两者为何各用其一见"v4"节。
